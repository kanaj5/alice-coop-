# alice-coop-
coop moding for Alice-1
Este es un mod, hecho para realizar la ejecución de co-op para el juego de American McGees Alice del remaster del 2011.

Este mod es una Alpha. No se han hecho pruebas de inicio a fin de todo el juego.

En el juego existe una mecánica para revivir a cualquiera de ambas Alice con el botón de acción, "Enter" o "B" dejando presionado por alrededor de 5s

Solo el host puede cargar y guardar partidas.

Si tiene instalado el MOD HD con VorpalFix.ini desactive esta variable: "DisableWinsockInitialization = 0" ES OBLIGATORIO para hacer funcionar el multijugador de Quake III

-El archivo Alice-Coop.bat es un Launcher para la función del mod
-Escohjes ser Host o cliente
-Muestra tu IP para compartirla si eres HOST.
-Entras como cliente y pide solo la IP del host.
-OBLIGATORIO ENTRAR POR ESTE .bat para poder jugar el mod

.Run the game wiht this file "Alice-Coop.bat" for playing this mod
